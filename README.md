# ESP32 Captive Portal

![C++](https://img.shields.io/badge/C++-ESP32-00599C.svg)
![Arduino](https://img.shields.io/badge/Arduino-Framework-00979D.svg)

A C++ implementation for the ESP32 microcontroller that turns the device into a standalone WiFi Access Point with an integrated Captive Portal.

## 🚀 Key Features

*   **DNS Redirection:** Automatically redirects all connected clients to a custom landing page.
*   **Standalone Server:** Hosts the web portal directly on the ESP32 internal storage.
*   **Customizable:** Easily modify the HTML/CSS of the landing page for branding or specific use cases.

## 🛠️ Tech Stack

*   C++ (Arduino / ESP-IDF)
*   ESP32 Web Server
*   DNS Server
